# CPS cross-framework experiments

The CPS rows in the paper were produced with the public CPS codebase
(<https://github.com/charlesCXK/TorchSemiSeg>, MIT licence). The CPS
adaptation used for SUIM, its configuration files and training logs are not
part of this release, so no CPS training entry point is provided here.

The U2PL cross-framework port, including the FGSR branch and its configs, is
available in `../u2pl/`.
